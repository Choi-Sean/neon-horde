## 1. 무기 리스트 (캐릭터가 고를 수 있는 것)

### 기본 8종 (레벨업 카드로 획득)
| 무기 | 한글 | 동작 | 조준 |
|---|---|---|---|
| Bolt | 볼트 | 가장 가까운 적에게 직선탄 (관통 성장) | 최근접 |
| Aura | 오라 | 몸 주변 원형 장판 지속 딜 | 자동 |
| Orbit | 궤도구 | 몸 주위 공전 구체 (접촉 딜) | 자동 |
| Whip | 채찍 | 이동/조준 방향 부채꼴 근접 스윕 | 이동 방향 |
| Seeker | 유도탄 | 유도 미사일 | 랜덤 타겟 |
| Lob | 화염구 | 포물선 투척 → 착탄 시 광역 | 랜덤 |
| Chain | 번개 | 적 사이 연쇄 튐 | 최근접 |
| Boomerang | 부메랑 | 던졌다 되돌아옴 (왕복 딜) | 이동 방향 |

### 진화 8종 (무기 만렙 + 짝 패시브 보유 시)
Bolt→**Railgun** · Aura→**Nova** · Orbit→**Halo** · Whip→**Reaper** ·
Seeker→**Swarm** · Lob→**Meteor** · Chain→**Tesla** · Boomerang→**Cyclone**

### 캐릭터 시작 무기
Pulse→Bolt · Volt→Chain · Aegis→Aura · Halo→Orbit

### 이미지 필요 여부
- **필수 아님.** 현재 `WeaponArt`가 절차적으로 손에 든 무기 실루엣을 생성 (archetype: 총/오브지팡이/포크/칼날/발사관). 레벨업 시 재생성되어 커지고, 진화 시 형태 변경.
- **퀄을 올리려면** 두 종류가 있으면 좋음:
  1. **무기 아이콘** 16개 (128px, 레벨업 카드 · 무기 목록 HUD용)
  2. **인게임 손 무기 스프라이트** 16개 (진화 포함)
- 없으면 지금처럼 절차적으로 굴러감. AI 생성 또는 에셋팩으로 대체 가능.
- **Arc 계열(Whip/Reaper)은 무기 스프라이트보다 "휘두르는 궤적 VFX"가 핵심** — 아트가 아니라 이펙트 문제 (아래 §2).

## 2. 채찍이 안 보이는 문제 (버그 + 누락)

- **손의 채찍**: `WeaponArt` Blade 스타일인데 Whip은 `tip=0` → 날이 degenerate → 얇은 손잡이만 그려짐. Reaper도 약함.
- **휘두름**: Arc 계열 발동 시 `DamageArc`만 호출하고 **시각 효과 0**. WeaponSystem은 비-Aura/Orbit에 머즐 플래시만.
- **수정**:
  1. `WeaponArt`: Whip = 손잡이 + 길고 얇은 곡선 꼬리(여러 마디), Reaper = 손잡이 + 큰 낫날 삼각형. tip 기본값 부여.
  2. 새 `ArcSlashVfx`: Arc 무기 발동 시 조준 방향으로 **부채꼴 네온 호가 0.12~0.18초 쓸고 지나감** (반투명, 무기 색). Aura는 원형 링 펄스, Orbit는 이미 구체가 보임.
  3. `WeaponSystem`이 발동 시 위치·방향·반각을 VFX에 전달.

## 3. 몬스터가 "진짜 몬스터"처럼 보이려면

현 상태: `CreatureArt` = 코드로 그린 실루엣 블롭 + 다리 6프레임. "도형보단 낫지만 진짜 몬스터는 아님"이 맞음. 한계 명확.

### 경로 3가지
| 방법 | 비용 | 결과 |
|---|---|---|
| **A. 절차적 개선** (내가 함, 무료) | 시간만 | 아웃라인 + 2톤 셰이딩 + 뚜렷한 실루엣(뿔/날개/꼬리/촉수/눈빛) + idle 흔들림 + 공격 모션. **VS·Brotato 초기 수준** 인디 실루엣까지 도달 |
| **B. 실제 스프라이트** (권장) | AI 생성 or 에셋팩(itch/CraftPix "monster sprite pack"/Asset Store) or 커미션 | 진짜 몬스터. 게임 룩이 완전히 달라짐 |
| **C. 하이브리드** | — | 지금 A로 다듬어 플레이 감 잡고, 아트 오면 슬롯 교체 (`SpriteBank` 구조 이미 존재) |

### 추천
**C.** 이번에 A로 실루엣 확 개선(아웃라인·뿔·꼬리·공격모션) → 동시에 B 소스 확보(몬스터 9종 + 보스 + 엘리트 변형, 탑다운, 일관 스타일, 투명배경, 종당 4~8프레임). 아트 넣으면 §6에서 교체.

## 4. 체력바를 캐릭터 밑으로

- 화면 하단 중앙 `HpBarBg/HpFill` 제거.
- **월드공간 미니 HP바**: 플레이어 발밑 ~0.7유닛, 카메라 추적. 폭 ~1.1유닛, 얇게. 피격 시 빨강 플래시. (옵션: 풀피 3초 후 페이드).
- 상단 XP바 + 타이머/레벨/킬 텍스트는 유지.
- 보스 체력바도 화면 상단 유지 (별개).

---

## 5. 몬스터 수 "적당히"

- `GameConfig.MaxEnemiesOnScreen` 600 → **180 (고사양) / 120 (저사양)**
- `DirectorSystem` 스폰레이트 `3.5 + t*0.4` (캡 60) → `2 + t*0.16` (캡 **26**)
- 초반 링 스폰 거리 9~13 유지, 엘리트 간격 22s 유지, 보스 시각 유지.
- 목표: "빽빽하게 몰리지만 화면이 안 보일 정도는 아님". 실기에서 재조정.

## 6. 완성도 체크리스트 (전체)

코어 루프(고정스텝 60Hz) · 적/투사체/획득물 풀링 렌더 · 플로우필드 경로 · 절차적 아레나(4테마) ·
무기 16 + 패시브 15 + 진화 8 · 레벨업/리롤/밴 · 캐릭터 4 + 고유 능력 · 코어/골드/퀘스트/영구강화/상점 메타 ·
보스 4회(5·10·15·20분) · 세이브(JSON) · 서비스 스텁(광고/IAP/계정/애널리틱스/동의) · 메뉴 전체 · 스플래시/아이콘 ·
졸라맨 플레이어(걷기 애니) · 손에 든 무기(조준·레벨반응) · EditMode 테스트 21

### 우선순위 (다음 작업 순서)
1. **플레이 체감 (즉시)** — 채찍 가시화 + Arc 슬래시 VFX · HP바 캐릭터 밑 · 몬스터 수 조절 · 몬스터 실루엣 개선(아웃라인/뿔/꼬리/공격모션)
2. **게임 필** — 히트스톱 · 넉백 · 처치 이펙트 강화 · 무기별 발사 이펙트 · 오디오(SFX 6 + BGM 1)
3. **콘텐츠 명료화** — HUD 무기/패시브 아이콘 · 레벨업 카드 아이콘 · 온보딩 3스텝
4. **밸런스 패스** — 실측 → 커브 조정
5. **로컬라이즈 마무리**
6. **실제 아트 교체** (아트 소스 확보 시)
7. **외부 연동 + 스토어 준비**

각 단계 끝에서만 APK 뽑음 (매 커밋마다 X).
