# NEON HORDE — 오마주 vs 차별점

레퍼런스: Vampire Survivors, Survivor.io, Monster Survivors.
"베꼈다"가 아니라 "장르를 따르되 축을 하나 비틀었다"가 목표.

## 이미 구현된 차별점

| 축 | 원조 계열 | NEON HORDE |
|---|---|---|
| **맵** | 사실상 빈 평면 (VS) 또는 고정 스테이지 | **매 런 절차적 유한 아레나** — 블로커·파괴 엄폐물·감속/해저드 지대·균열. 테마 4종이 지형 스타일과 몬스터를 결정 |
| **적 이동** | 순수 플레이어 추적 | **플로우 필드 길찾기** — 장애물을 실제로 우회. 지형을 방패로 쓰는 플레이가 성립 |
| **파괴 상호작용** | 지형 없음 | 파괴 가능 엄폐물 → 통로 개방, 크레이트 부수면 보상 |
| **런 변주** | 시드만 | 테마 × **모디파이어 1~2개**(적 이속+/골드+/엘리트2배/지형밀도+/쿨다운-·적HP+) |
| **비주얼** | 픽셀아트 | 기하학/네온 + Bloom — 총알지옥 가독성 우선, 아트 파이프라인 0 |

## 추가로 넣으면 좋은 차별화 아이디어

### A. 지형을 능동적으로 쓰게 만들기 (엄폐 메타)
- **엄폐 보너스**: 최근 2초간 블로커에 인접해 있었으면 "은신" — 새 적 스폰이 플레이어를 덜 조준. 리스크: 갇히면 위험.
- **파괴 콤보**: 파괴 엄폐물을 무기로 부수면 파편이 튀어 근처 적에게 관통 데미지. "환경을 무기화."
- **붕괴 유도**: 특정 무기(레일건 진화)가 블로커를 관통하며 뒤의 균열을 넓혀 적을 낙사시킴.

### B. "빌드"를 더 극단적으로
- **무기 슬롯 6개 대신 3개 + 각 무기 레벨 상한 12**: 얕고 넓게 vs 좁고 깊게 선택 압박. (VS는 8슬롯 = 다 채움)
- **금단 특성(Forbidden)**: 레벨업에 가끔 등장. 강력하지만 페널티 동반 (예: "데미지 2배, HP 재생 불가"). 로그라이트 결정 강화.

### C. 아레나 이벤트 (절차 지형이니까 가능)
- 3분마다 아레나 한쪽이 **붕괴/침수** 시작 → 안전지대가 좁아짐. 플레이어를 계속 움직이게 강제.
- **문(Gate)**: 부수면 다음 테마의 미니 구역이 열리고 그 테마 몬스터+보상이 쏟아짐. 위험/보상 선택.

### D. 메타 훅
- **아레나 청사진 수집**: 특정 테마에서 오래 버티면 그 테마의 "레이아웃 프리셋"을 언락 → 다음 런에서 선호 테마 지정 가능. (맵이 절차적이라 성립하는 수집 요소)
- **일일 챌린지 = 전원 동일 시드 + 동일 모디파이어** → 로컬/서버 순위. 이미 시드 고정은 구현됨.

### E. 캐릭터 능력을 지형과 엮기
- PULSE 충격파 → 적뿐 아니라 **파괴 엄폐물도 부숨** (길 열기).
- AEGIS 무적 → 무적 중 **해저드 지대 무시**하고 가로지르기.
- HALO 레벨업 폭발 → 폭발 범위 내 **균열 확장**.
→ "이 캐릭터는 이 지형에서 강하다" 라는 조합 재미. 원조엔 없음.

## 권장 채택 순서 (구현 난이도 낮은 순)
1. **B의 금단 특성** — `UpgradeGenerator`에 항목 추가만. 반나절.
2. **E의 캐릭터×지형** — 이미 능력 훅 있음. 각 능력에 `Arena.DamageCrate` 한 줄씩. 반나절.
3. **A의 파괴 콤보** — 파괴 시 파편 투사체 스폰. 1일.
4. **C의 아레나 이벤트(수축)** — `Arena`에 안전지대 반경 타이머 + 밖이면 지속 데미지. 1~2일.
5. **D의 아레나 청사진** — 메타 수집. 2일.

1·2번만 해도 "왜 이 게임은 다르지?"에 대한 답이 명확해진다.
