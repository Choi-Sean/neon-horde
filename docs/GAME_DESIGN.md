# NEON HORDE (가제) — 게임 기획서

> 장르: Survivor-like (bullet-heaven / auto-battler roguelite)
> 레퍼런스/오마주: Vampire Survivors, Survivor.io, Monster Survivors
> 플랫폼: iOS / Android · 엔진: **Unity 6 LTS (URP 2D)**
> 목표: 심플한 조작, 강한 "한 판 더" 중독성, 솔로 개발로 소프트런치까지

---

## 1. 한 줄 소개

한 손으로 캐릭터를 움직이기만 하면 무기는 자동으로 발사된다. 화면을 뒤덮는 몬스터 떼를 뚫고 살아남으며, 레벨업마다 무기와 특성을 골라 나만의 빌드를 완성한다.

---

## 2. 코어 루프 (런 1회, 3~20분)

```
조이스틱으로 이동  ──▶  무기 자동 발사  ──▶  몬스터 처치  ──▶  경험치 젬 드랍
      ▲                                                            │
      │                                                            ▼
   HP 0 = 런 종료  ◀── 접촉 데미지 ◀── 몬스터 추격      경험치 획득(자석 반경)
      │                                                            │
      ▼                                                            ▼
  결과 화면 / 골드 정산                              레벨업 → 일시정지 → 3택 1 업그레이드
```

- 시간이 지날수록 스폰량·몬스터 강함 증가 (Director가 시간 기반으로 난이도 상승)
- 5:00 / 10:00 / 15:00 마다 보스, 20:00 생존 시 클리어(승리)
- 엘리트 처치 시 상자 → 보너스 업그레이드
- 골드 코인 드랍 → 런 종료 후 메타 재화로 정산

## 3. 메타 루프 (런과 런 사이)

| 요소 | 내용 |
|---|---|
| **영구 업그레이드 상점** | **골드**로 구매. 시작 HP, 데미지 %, 이동속도, 자석 반경, 행운, 부활 횟수, 시작 무기 슬롯, 골드 획득량 등 |
| **캐릭터 언락** | **코어(Core)** 재화 또는 **직접 결제(IAP)** 로 해금. 기본 캐릭터 1 + 해금 캐릭터 3 (총 4). 캐릭터마다 시작 무기 + 고유 능력 + 스탯 편향이 다름 |
| **퀘스트** | 일일 + 마일스톤. 보상은 주로 **코어** (+ 소량 골드). 코어의 주 획득처 |
| **무기 언락** | 퀘스트/업적 달성 시 무기 풀에 추가 (레벨업 선택지에 등장) |
| **일일 챌린지** | 고정 시드 런, 순위 비교(로컬 → 추후 서버) |

### 3.1 재화 3종

| 재화 | 획득 | 사용처 | 비고 |
|---|---|---|---|
| **골드 (Gold)** | 런 중 드랍 → 종료 시 정산 | 영구 업그레이드 상점 | 인게임 파밍 재화 |
| **코어 (Core)** | 퀘스트 보상 / IAP 번들 | 캐릭터 해금 | 하드 재화. 무료로도 모을 수 있음 |
| (프리미엄 잼) | *v1 후순위* | — | 필요 시 M6 이후 |

- 캐릭터는 **코어로 해금** 하거나 **캐릭터별 IAP로 직접 구매** — 둘 다 가능. (기본 캐릭터는 처음부터 보유)

### 3.2 캐릭터 (4)

| 캐릭터 | 시작 무기 | 고유 능력 | 스탯 편향 | 해금 |
|---|---|---|---|---|
| **PULSE** (기본) | 볼트 | 5초마다 자동 충격파(넉백) | 균형 | 처음부터 보유 |
| **VOLT** | 체인 라이트닝 | 처치 시 10% 확률 연쇄 폭발 | 데미지 ↑ / 최대 HP ↓ | 60 코어 or IAP |
| **AEGIS** | 오라 | HP 30% 이하 시 3초 무적 (쿨 20초) | 최대 HP ↑ / 이동속도 ↓ | 90 코어 or IAP |
| **HALO** | 궤도구 | 경험치 +25%, 레벨업 시 주변 폭발 | 시작 HP −25% | 120 코어 or IAP |

*(능력·수치는 플레이스홀더, `CharacterDef`에서 튜닝)*

### 3.3 맵 — 매 런 다르게 (절차적 지형/장애물 생성)

- 하드코딩 스테이지 없음. **런 시작 시 시드로 유한 아레나를 생성**: `테마 × 지형 시드 × 모디파이어`
- **유한 아레나** (약 70×70 ~ 110×110 유닛, 가시 경계벽). 무한 평면 아님 → 유한 격자에서 지형 생성 + 길찾기가 깔끔
- **절차적 지형 요소** (시드로 배치, 테마가 스타일·밀도 결정):

| 요소 | 효과 |
|---|---|
| 블로커 (기둥/바위/벽 조각) | 통과 불가. 이동·투사체 차단 |
| 파괴 가능 엄폐물 (크레이트) | HP 보유, 부수면 통로 개방 (+가끔 소량 보상) |
| 감속 지대 (진흙/빙판/가시덤불) | 통과 가능하나 이동속도 −%, 빙판은 관성 |
| 해저드 지대 (용암/전류) | 밟으면 지속 데미지 |
| 임패서블 (균열/구덩이) | 통과 불가, 투사체는 통과 |

- 생성 규칙: 시작 지점 주변은 안전 반경 확보, 아레나 연결성(고립 구역 없음) 보장, 밀도는 테마+모디파이어로 조절
- **맵 테마 4종** (지형 스타일 · 몬스터 세트 · 팔레트 · 해저드 · BGM):

| 테마 | 지형 스타일 | 해저드 지대 | 몬스터 세트 |
|---|---|---|---|
| **GRID** | 성긴 네온 기둥, 개방적 | 없음 | 워커 / 스워머 / 탱크 |
| **VOID** | 떠 있는 파편 섬 + 균열(임패서블) | 간헐 시야 축소 | 팬텀 / 스플리터 / 워커 |
| **FURNACE** | 좁은 통로, 파괴 가능 잔해 많음 | 용암 웅덩이 | 익스플로더 / 탱크 / 스피터 |
| **CRYO** | 빙판 감속 지대 넓음 | 전류 지대 | 스워머 / 프로스트탱크 / 스피터 |

- **모디파이어** (런마다 1~2개 랜덤): "적 이속 +15%, 골드 +20%" · "엘리트 2배" · "지형 밀도 ↑" · "무기 쿨 −10%, 적 HP +20%"
- 생존 시간이 길수록 어려운 테마/모디파이어 가중 ↑
- → "항상 다른 맵" = 테마 4 × 지형 시드(무한) × 모디파이어 조합. 테마는 이후 확장

> 설계 주의: 장애물 + 호드 = 순수 "추적 AI"가 벽에 낌 → **플로우 필드 길찾기** 필요 (ARCHITECTURE §5·§8). 미로가 아니라 "엄폐물 있는 개방 아레나"로 튜닝해 플레이어가 구석에 몰려 즉사하지 않게.

### 3.4 몬스터 — 맵마다 다르게

- 몬스터는 **맵 테마에 귀속**. 위 표의 세트 + 공통 엘리트/보스
- 각 `EnemyDef`는 어느 테마에서 어떤 가중치로 등장하는지 보유
- 보스는 테마별 스킨/패턴 변형 (기본 3패턴 + 테마 컬러/속성)

### 3.5 퀘스트

- **일일 퀘스트** (매일 3개 로테이션): 예) "3판 플레이" → 5 코어 · "몬스터 1000 처치" → 5 코어 · "10분 생존" → 8 코어
- **마일스톤 퀘스트** (1회성): 예) "VOID에서 보스 처치" → 15 코어 · "레벨 30 도달" → 20 코어 · "PULSE로 15분 생존" → 25 코어
- 완료 → 수동 "수령"(claim) → 코어 지급
- `QuestDef`: id, 설명, 목표 타입(플레이수/처치/생존시간/레벨/보스처치/테마조건), 목표치, 보상(코어, 골드)

## 4. 조작

- **이동**: 가상 조이스틱 (화면 좌/우 선택 가능) 또는 화면 아무 곳 드래그
- **무기**: 전부 자동. 조준은 무기별 규칙(가장 가까운 적 / 진행 방향 / 주변 전체 등)
- **일시정지**: 상단 버튼
- 그 외 인게임 입력 없음 (레벨업 시 카드 3개 중 탭)

---

## 5. 무기 (MVP 8종, 이후 확장)

각 무기 레벨 1~8, 레벨업 시 데미지 / 발사수 / 범위 / 쿨다운 / 관통 / 지속시간 중 일부 상승.

| 무기 | 동작 | 조준 |
|---|---|---|
| 볼트 (Bolt) | 직선 투사체, 빠름 | 가장 가까운 적 |
| 오라 (Aura) | 주변 원형 지속 데미지 | 자동(범위) |
| 궤도구 (Orbit) | 플레이어 주위를 도는 구체 | 자동(회전) |
| 채찍 (Whip) | 진행 방향 부채꼴 참격 | 진행 방향 |
| 유도탄 (Seeker) | 적을 추적하는 미사일 | 랜덤/가장 가까운 적 |
| 화염구 (Lob) | 포물선으로 던져 착탄 시 AoE | 랜덤 지점 |
| 번개 (Chain) | 랜덤 적 타격 후 인접으로 연쇄 | 랜덤 |
| 부메랑 (Boomerang) | 나갔다 돌아오며 관통 | 진행 방향 |

- **무기 진화 (M4)**: 특정 무기 만렙 + 특정 특성 보유 시 상위 무기로 진화 (VS 시그니처 메커니즘)

## 6. 특성 / 패시브 (MVP 12종)

데미지 %, 공격속도(쿨다운 감소), 범위 %, 투사체 +1, 지속시간 %, 이동속도, 최대 HP, HP 재생, 방어력, 자석 반경, 경험치 획득 %, 행운.
추가(M4): 저주(적 증가 + 보상 증가), 부활, 회수(재획득).

## 7. 몬스터 (MVP)

- 공통 타입 풀. 각 몬스터는 **어느 맵 테마에서 어떤 가중치로 등장하는지** 를 `EnemyDef`에 보유 (3.4 참고)

| 타입 | 특징 | 주 등장 테마 |
|---|---|---|
| 워커 | 기본, 플레이어 추적 | GRID / VOID |
| 스워머 | 빠르고 약함, 다수 | GRID / CRYO |
| 탱크 | 느리고 HP 높음 | GRID / FURNACE |
| 스피터 | 원거리 투사체 | FURNACE / CRYO |
| 익스플로더 | 접근 후 자폭 | FURNACE |
| 스플리터 | 죽으면 소형 2마리로 분열 | VOID |
| 팬텀 | 반투명, 빠름, HP 낮음 | VOID |
| 프로스트탱크 | 탱크 + 피격 시 주변 슬로우장 | CRYO |
| **엘리트** | 큰 개체, 상자 드랍 (전 테마 공통) | — |
| **보스** | 5/10/15/20분, 3패턴 + 테마 컬러/속성 변형 | — |

- 몬스터 HP/속도/스폰량은 경과 시간의 함수로 스케일링 (`BalanceConfig` 커브)

## 8. 맵 / 스테이지

- **유한 아레나** (약 70~110 유닛 사각, 경계벽). 카메라는 플레이어 추적, 경계 근처에서 클램프
- **매 런 절차 생성**: `MapThemeDef(4종) × 지형 시드 × 모디파이어(1~2)` (3.3 참고)
- `MapGenerator`: 시드 → 아레나 크기·경계 → 지형 요소 배치(블로커/파괴엄폐물/감속지대/해저드/임패서블) → 시작 안전반경 → 연결성 검증 → nav 격자(blocked/slow 셀) 산출
- `MapThemeDef`: id, 팔레트/배경, 지형 스타일 파라미터(밀도·요소 가중치), 몬스터 세트(EnemyDef 가중치), 해저드, BGM, 보스 스킨
- 적 이동은 **플로우 필드**(플레이어 방향) 기반 — 장애물 우회. 지형 없는 지역은 직접 추적으로 폴백
- 제한시간 기본 20:00, 20분 생존 = 승리
- 생존 시간이 길수록 어려운 테마·모디파이어 가중 ↑

## 9. 수익화 — 라이트

### 9.1 리워드 광고 (전부 선택적, 강제 없음)

| 배치 | 보상 |
|---|---|
| `revive` | 사망 시 부활 1회 (런당 1회) |
| `double_gold` | 런 종료 후 골드 2배 |
| `reroll` | 레벨업 선택지 리롤 (또는 인게임 재화) |
| `chest_x2` | 상자 보상 2배 |

- 인터스티셜 없음. 배너 없음.

### 9.2 IAP

| 상품 | 내용 |
|---|---|
| `char.volt` / `char.aegis` / `char.halo` | 캐릭터 개별 직접 해금 (코어 없이 즉시) |
| `cores.small` / `cores.medium` / `cores.large` | 코어 번들 (캐릭터/기타 해금용) |
| `remove_ads` | 리워드 광고 유지, 향후 배너 계열 제거 (선택) |
| `starter_pack` | 코어 + 골드 + 광고 제거 묶음 (선택) |

- 캐릭터는 **코어(무료 획득 가능)** 또는 **개별 IAP** 어느 쪽으로도 해금 → 페이 게이트 아님
- iOS ATT 동의 / UMP 동의 폼 / 미동의 시 비개인화 광고
- 광고 미충전(no fill) 시 버튼 비활성 또는 소프트 재화 대체 제공

## 10. 진행/난이도 곡선 (수치는 `balance_config.dart`로 분리)

- `xpToNext(level)` = 완만한 지수 (초반 레벨업 빠르게 → 도파민)
- `enemyHpScale(t)`, `spawnRate(t)` = 시간에 따라 증가하는 커브
- `eliteInterval`, `bossTimes = [300, 600, 900, 1200]`
- `upgradeChoiceCount = 3`, `rerollCost`, `reviveInvuln`, `magnetBase`
- 인앱 디버그 메뉴: 스폰 강제 / 경험치 지급 / 무적 / 시간 스크럽 / 무기 즉시 최대

| 리스크 | 대응 |
