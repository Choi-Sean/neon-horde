# NEON HORDE — 스토어 등록 초안

> 심사 전 최종 검토 필요. 이름/가격/URL은 확정 후 교체.

## 이름
- 한국어: **네온 호드 (NEON HORDE)**
- English: **NEON HORDE**
- (스토어 이름 중복 시 "NEON HORDE: Survivor" 등 접미사)

## 짧은 설명 (Play: 80자)
- KO: 절차적 네온 아레나에서 무기는 자동, 너는 살아남기만 하면 된다.
- EN: Auto-fire weapons, procedural neon arenas — just survive the horde.

## 프로모 문구 (App Store: 170자)
- KO: 한 손으로 움직이면 무기는 알아서 쏜다. 매 판 새로 생성되는 지형과 장애물, 4가지 테마의 몬스터 떼. 레벨업마다 3장의 카드로 나만의 빌드를 완성하고 20분 생존에 도전하라.
- EN: Move with one thumb; your weapons fire themselves. Every run generates a fresh arena with cover and hazards. Pick from 3 cards each level-up, build your loadout, and try to survive 20 minutes.

## 상세 설명
```
■ 초간단 조작
드래그(또는 조이스틱)로 이동만. 무기는 전부 자동 발사.

■ 매 판 다른 전장
빈 평면이 아니다. 시드로 생성되는 유한 아레나 — 엄폐물, 파괴 가능한 잔해, 감속 지대,
용암/전류 해저드, 균열. GRID · VOID · FURNACE · CRYO 4가지 테마마다 지형과 몬스터가 다르다.
적은 플로우 필드로 장애물을 우회하니, 지형을 방패로 써라.

■ 빌드 로그라이트
볼트·오라·궤도구·채찍·유도탄·화염구·번개·부메랑 8종 무기와 12종 특성.
레벨업마다 3장 중 1장. 무기 만렙 + 짝 특성 → 상위 무기로 진화. 리롤·삭제로 운을 통제.

■ 캐릭터 4종
PULSE(균형)·VOLT(화력)·AEGIS(생존)·HALO(성장). 저마다 시작 무기와 고유 능력.
코어(퀘스트 보상)로 해금하거나 직접 구매.

■ 5·10·15·20분 보스, 20분 생존 = 승리
■ 일일 챌린지 — 전원 동일 시드
■ 광고는 전부 선택(부활·골드 2배·리롤). 강제 전면 광고 없음.
```

## 스크린샷 촬영 리스트 (각 3~6장)
1. 수백 마리 호드에 둘러싸인 순간 + XP바/타이머 HUD
2. 레벨업 3택 카드 화면
3. FURNACE 테마 — 용암 웅덩이 + 좁은 통로 + 보스 배너
4. CRYO 테마 — 빙판 감속 지대 + 프로스트탱크
5. 무기 진화 카드("진화 → 레일건")
6. 메인 메뉴 — 캐릭터 4종 / 코어·골드
7. (세로 영상 15~30초) 이동 → 자동공격 → 레벨업 → 보스 → 승리
